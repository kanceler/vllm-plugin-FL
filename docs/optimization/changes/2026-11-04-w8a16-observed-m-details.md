# 沐曦已观测 M：原生 BF16 GEMM 基准详细对比

2026-11-04 补充既有数据；没有运行新 GPU 测试或修改 Kernel。本文是同日 observed-m-progress 报告的明细补充。

## 口径与弃用决定

基准固定为 `bf16_original = metax_mm.mm(x, original_weight.t())`，即该实验版本的原生 BF16 权重 MM 完整调用；并非 CUDA 厂商库或单个 GPU event 时长。Dense、Split-K、Separate 均测完整调用。加速比 = BF16耗时 / 候选耗时；耗时降低率 = 1 - 候选耗时 / BF16耗时。量化后 BF16(Q) MM 仅作诊断，不替代基准。

**按用户最新决定：scale-before-dot 因精度计算契约不一致永久退出当前候选及后续测试；历史记录只作归档，不重跑、不作为收益依据。** 本表 Dense/Split-K 为 BF16 dot、FP32 累加后 scale；Separate 为转换 + BF16 MM + 输出后 scale，保留其 BF16 中间舍入差异。

环境、计时协议、正确性和局限见 [进度报告](2026-11-04-w8a16-observed-m-progress.md)。时间单位均为 μs，取五轮交错终测的中位数；范围为五轮样本 min–max，不是置信区间。显示值经过舍入，计算使用原始精度。赢家仅指三算法内部最快，不代表快于 BF16。
