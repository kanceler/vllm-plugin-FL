# 天数四投影 Separate 与 BF16 MM 大候选池对照

## 1. 基本信息与摘要
2026-11-13，天数Iluvatar BI-V150，驱动4.5.0，Torch2.10.0、Triton3.6.0。分支 `perf/tianshu-four-projection-separate-micro`。新增 `benchmarks/diagnostics/benchmark_tianshu_four_separate.py`。12个Shape全部完成，仅合成microbench，不改变模型运行路径及官方参数。大M部分投影可接近原生MM，但M64明显更慢，不支持全Shape统一Separate。

## 2. 问题与原因分析
已有近期完整调优主要针对Down，不能把其转换和scale融合收益推广至Gate/Up、QKV、O。原生MM也需相同范围搜索，避免与未调优基线比较。历史结果不作为本轮成绩。

## 3. 具体实现
复用天数backend的INT8到BF16转换、NK及KN布局和scale融合MM。每次分配、转换及融合MM全部保留在计时函数内；不缓存BF16权重。激活BF16，权重对称per-output-channel INT8，scale FP32，dot使用BF16、FP32累加。不是原生INT8 GEMM。

四投影N/K依次为Down 2048/6144、GateUp 12288/2048、QKV 2560/2048、O 2048/2048；M仅64、2048、4096。原生、Separate NK、Separate KN各搜索518组MM配置，每一组合执行正确性及完整调用计时；Separate每布局前四个配置交叉搜索15组NK或27组KN转换参数。每路径选前三候选，用两个独立seed、五轮随机交错、eager及图重放复测。只称所测范围内较优，有限分阶段搜索不保证联合全局最优；不搜索Split-K。

## 4. 实验与验证
本地AST语法检查通过。正式结果目录为远端 `/workspace/experiments/tianshu-four-separate-20261113-01/results-v2/`，存在COMPLETE。共22824条尝试记录：MM初筛18648条（14796成功，3852共享内存超限），转换交叉2016条全部成功，最终2160条计时全部通过。共108个领先候选，每个候选两seed×五轮×eager/graph，计时缓存未复用；Triton磁盘编译缓存未清理，不把尝试数当作新编译数。

预定误差门槛relative L2不超过0.005、normalized max不超过0.01，所有有效候选通过有限值和该门槛，最大L2为0.001662299、最大normalized max为0.003684253。原生参考为FP32 A×W，Separate参考为FP32 A×Q后乘FP32 scale；此处检查Kernel误差，不将权重量化误差合并或用这些值代替模型精度。权重量化误差未单独归档，模型精度、吞吐及TTFT未测。
