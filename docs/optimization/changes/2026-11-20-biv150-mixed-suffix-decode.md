# BI-V150 Mixed Attention 后缀 Decode 分相

## 基本信息与摘要

2026-11-20，Iluvatar BI-V150。以 submission 完整组合为基线，在 `vllm_fl/attention/static_kv_compat.py` 增加长 Prefill 在首、连续单 token Decode 在后的静态 KV 分相。

## 问题与原因分析

现有策略只识别开头连续的单 token 请求。一个 4041 token Prefill 在首时，其后的 55 个 Decode 随整批进入 2D Attention。

## 具体实现

根据 CPU Query 前缀判定首行长 Prefill 及 16–80 条后继 Decode，校验 scratch 容量，每 step 重基准 Decode 的设备前缀。对 Q 和输出按 token 位置切片，对 block table 和序列长度按请求行切片。静态 INT8 KV 数据和物理 token scale 保持原格式，复用现有 3D Decode、Reduce 与 2D Prefill。

## 实验与验证

独立实模小测比较完整组合现有路径与直接切片。观察 529 个 mixed step，探测 5 组首版命中。每组 20 次配对，100 次全部加速，被测层完整 Attention 调用中位数节省 5.28–6.00 ms。Prefill 输出一致，最差 Decode 单行相对 L2 为 1.13e-3。14 项既有 CPU 兼容性测试与 9 项后缀布局和映射检查通过。完整模型 step 和候选 16K 结果待验证。首次候选启动因源码指纹不匹配退出。更新 Static KV 两份配置及量化集成清单的指纹后，在隔离目录逐项核对集成清单并重新启动。

### 16K 两轮诊断进度

第 1 轮 baseline 和候选均为 128/128 成功，输入 token 2097152，输出 token 131072。候选 772.55 s、2884.24 tok/s、Mean TTFT 91284.36 ms。同轮历史对照分别为 817.14 s、2726.87 tok/s、76803.56 ms，对应时间 −5.46%、吞吐 +5.77%、Mean TTFT +18.85%。Median 和 P99 TTFT 分别增加 57.83% 和 7.73%。该轮按既定口径跳过，第二轮已完成。候选 3122.01 tok/s、Mean TTFT 72383.72 ms，128/128 成功。归档基线第二轮分别为 3095.75 tok/s、71946.17 ms，对应吞吐 +0.85%、Mean TTFT +0.61%。首版未达到 +3% 诊断目标。首轮吞吐差值超过首版覆盖推算的量级，归因待验证。

### 覆盖复核

最新改前小测中 529 个 mixed step 仅 5 次命中首版。较早一轮的 537 个 mixed step 中，广义单长行策略命中 130 次。其中原本完全未分相且长行在首有 7 次，长行在中间有 91 次，基线已有部分分相有 32 次。按 42 层线性外推，7 次首版命中、每层节省 5.28–6.00 ms 对应约 1.55–1.76 秒 GPU 时间，尚未扣除集成开销。归档基线第 2 轮为 719.77 秒，同 token 数下 +3% 吞吐要求缩短约 20.96 秒。此前约 28 秒的估算对应更广候选。居中布局有两组实模配对代表值，收集回写后分别节省 6.43 和 4.84 ms/层，实际覆盖加权及整步收益待验证。

历史探测的计时去重键没有长行位置。按原键并额外要求同为居中布局时，91 次居中命中仅 3 次有可匹配的实模配对。不能把两组已测数值按 91 次直接加权。新的三路诊断在去重键中加入前缀长度分桶，覆盖不同长行位置，再估算整轮收益。

91 个居中命中的前后 Decode 数分别为 1–15 和 39–54。后续独立实模 A/B 可在相同输入下测试两种候选。其一将两侧 Decode 收集后做一次 3D 并写回。其二保留短 Decode 前缀和长 Prefill 在同一 2D launch，只切出长行后的连续 Decode 后缀做 3D。两者都应与原完整组合的实际路径对照，计入所有 launch、Reduce 和搬运，分别核对前缀、Prefill、后缀的输出误差。第二种省去收集回写，但保留了前缀 Decode 的 2D 成本。实际排序待配对计时。本轮 GPU 被候选诊断占用，后续独立测试串行执行。

### 居中布局三路实模小测

观察 529 个 mixed step，其中 91 次命中居中条件，15 组同输入计时覆盖全部命中分桶。相对原完整组合，两侧收集回写净省 4.68–6.38 ms/层，中位 5.68 ms。只切后缀净省 3.98–5.96 ms/层，中位 4.79 ms。收集回写在 14/15 组节省更多。按实际分桶和 42 层外推分别是 21.90 s 和 18.96 s GPU 时间，尚待完整 step 和整轮墙钟验证。两种策略的 Prefill 均一致，最差 Decode 单行相对 L2 均为 1.46e-3。优先接入两侧收集回写，保留首版连续切片路径。原始记录见容器 `/workspace/experiments/tianshu-mixed-interior-20261120-01/audit`。
