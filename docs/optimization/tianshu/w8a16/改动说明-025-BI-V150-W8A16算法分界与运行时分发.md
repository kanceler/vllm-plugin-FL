# 改动 #025：BI-V150 W8A16算法分界与运行时分发

> 平台：天数BI-V150；模型：MiniCPM5-2B。本文整理历史实验，并非本分支已经接入该代码或重新完成验证。

## 1. 为什么这样改

不同投影与M大小下算法成本不同，不能把单一阈值当作通用能力约束。

## 2. 改动内容

按N/K、M、设备、布局和提供者版本加载离线策略，Down小M使用专用Split-K、大M使用Separate；未知shape或失效版本回退通用转换路径，保留Dense及其他合法算法。

先检查dtype、地址、stride、分片和资源合法性，再按设备、M/N/K、软件与provider选择候选；同算法相邻采样点可以复用已测配置，不同算法间未采样间隙保守采用Separate。采样阈值是性能策略而非能力条件。

## 3. 开关、适用范围与Graph安全

按真实设备、dtype、布局、资源和提供者版本检查能力；非目标模式保留合法路径。四项投影开关和已量化权重回退以被测版本为准。

版本或shape不匹配使用通用Separate，仍然每次将INT8转换BF16；公开BF16 MM可能先对中间输出舍入，需与融合scale参考分开。图内不发起调优，策略更新必须隔离服务进程。

## 4. 收益与正确性验证

观察到Down 256～264、Gate/Up 192～200、QKV/O 128～136附近交界，属于所测配置范围；9个代表M验证策略匹配、误差过门槛不代表模型全M或耗时覆盖。实际模型精度及同提供者官方消融待验证。

### 留出点与实际入口检查

最终覆盖与留出混合集合为52点、312条图计时，21点较快、31点较慢；其中真正未参与调优的38点为14点较快、24点较慢，最差Gate/Up M199额外耗时约61.04%。对照使用最近实测BF16配置，不能把点数当模型耗时覆盖。合成入口覆盖67个普通调用及更新输入graph，并检查非连续输入、bias及dtype；未做该阶段官方模型精度或性能测评。
