# 改动 #022：BI-V150 W8A16权重量化与四投影接入

> 平台：天数BI-V150；模型：MiniCPM5-2B。本文整理历史实验，并非本分支已经接入该代码或重新完成验证。

## 1. 为什么这样改

权重读取占GEMM成本，需在压缩权重后控制反量化和模型精度。

## 2. 改动内容

静态对称per-output-channel INT8权重与FP32 scale；激活BF16，INT8转换BF16后dot、FP32累加并输出BF16。Down、Gate/Up、QKV、O独立开关默认关闭；LM Head保持BF16。

模型加载时在本地TP分片上按输出通道生成INT8权重和FP32 scale，原外层bias与TP通信顺序保留；运行时按投影和shape调用相应算法。Down、Gate/Up、QKV、O是独立选择，不能以四个开关存在推定全部投影已完成模型精度验收。

## 3. 开关、适用范围与Graph安全

按真实设备、dtype、布局、资源和提供者版本检查能力；非目标模式保留合法路径。四项投影开关和已量化权重回退以被测版本为准。

历史天数实现的 `VLLM_FL_TIANSHU_W8A16_DOWN`、`GATE_UP`、`QKV`、`O` 四项完整名称均以相同 `VLLM_FL_TIANSHU_W8A16_` 前缀开头，默认0，加载前读取；开关改变需新服务。未知版本回退仍使用量化权重的临时BF16转换，不是原始BF16副本。

## 4. 收益与正确性验证

四投影算子与运行入口分别验证，不能将开关存在等同模型覆盖。天数最终组合未完成单独官方模型精度验收；不继承沐曦精度与吞吐。
